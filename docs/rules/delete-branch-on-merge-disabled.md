✅  This rule is stable.

🛠️ This rule is automatically fixable by the `--fix` command-line option.

⚙️ This rule is configurable

## What it does

Checks that automatically delete head branches is disabled for a repository.

## Configuration

Example:

```yaml
target: false
```
